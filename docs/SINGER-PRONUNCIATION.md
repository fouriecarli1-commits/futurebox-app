## 1. What this is about

The Speaker reads and sings a list of words and lines. The Studio records it and
uses it to get the app's **pronunciation** right: how an Afrikaans word has to be
written so that an AI voice says it correctly.

The recording is a measuring stick, not a product.

## 2. What the Studio may do with the recording

Only these three things:

1. **Listen to it**, and write pronunciation rules from it — how a word should be
   respelled, or which phonetic symbols belong to it.
2. **Compare it** with what the app's own voices pronounce, to test whether a rule
   works. That is the only way to be sure a rule is an improvement and not merely
   a change.
3. **Keep it** for as long as the rules that came out of it are in use, so that a
   year from now somebody can check where a rule came from.

## 3. What the Studio may NOT do

This is the heart of this document and the reason it is short.

The Studio will **not**:

1. **make a voice model of the Speaker.** No cloning, no RVC, no training of any
   model on this recording. Not now and not later, unless the Speaker signs a
   separate agreement (`docs/SINGER-AGREEMENT.md`);
2. **publish the recording** — not in the app, not as a demonstration, not on
   social media, nowhere. Nobody outside the Studio hears it;
3. **use the recording in a released song**, including as a guide vocal underneath
   another voice. *(If the Studio ever wants to, that is a different thing with a
   different fee — see clause 6.)*;
4. **give the recording to a third party**, except where a processor is needed to
   store the file, and then only for storage.

## 4. On POPIA

A voice recording is still personal information, so it is still handled properly:

- The Speaker hereby consents to the purpose in clause 2.
- The Studio is the responsible party. The file stays in the Studio's own storage;
  it does **not** go to Kits.AI or to any voice service, because there is no model
  to train.
- The Speaker may ask what is held, and may use clause 5 to have it deleted.

Because there is no model and no publication, this is a much smaller thing than the
voice-model agreement — and it is deliberately kept that way.

## 5. Stopping

The Speaker may ask in writing at any time for the recording to be deleted. The
Studio deletes it within **thirty days**.

**Rules already written remain.** A respelling like `tjie → kie` is a fact about
the Afrikaans language, not a piece of somebody's voice, and it cannot be
withdrawn. That is the only thing that remains, and the Speaker should know it
before signing — it is also why this clause is not the hard one that appears in the
voice-model agreement.

The fee stays paid.

## 6. If it later becomes more

Two things would need a new agreement, and both are entirely fair to ask for:

| If the Studio wants to | What is then needed |
|---|---|
| Make a voice model of the Speaker | `docs/SINGER-AGREEMENT.md`, signed separately |
| Use the recording as a guide vocal under a released song | a session fee for a performance, in writing, before release |

The second is easy to overlook. A guide vocal that has been converted is still the
Speaker's **performance** underneath that song, and a performance in a commercial
release is not the same thing as a reference in a workshop.
